# Outlook Not Syncing – Acme Corp

## Quick fixes
1. Check the status bar: if it says "Working Offline", go to Send/Receive > Work Offline to toggle it off.
2. Restart Outlook while holding **Ctrl** to launch in Safe Mode and rule out add-ins.
3. Mailbox limit is **50 GB**; above 49 GB sending is blocked. Archive old mail via File > Tools > Mailbox Cleanup.

## Rebuild the profile
Control Panel > Mail > Show Profiles > Add a new profile, sign in, set it as default.

## Shared mailboxes not appearing
Shared mailboxes auto-map within 60 minutes of access being granted. If still missing after 2 hours, raise a ServiceNow ticket to the Messaging team.
